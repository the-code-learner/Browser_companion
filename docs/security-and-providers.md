# Security, consent and provider notes

## Human authority for browser actions

The model proposes; the user makes the final decision for actions that change page state. Read-only observation/research steps may run automatically. All browser-interaction plans (including navigation, scrolling, highlighting and clicks) require a fresh user confirmation; high-risk and sensitive actions also require typing a phrase. A worker-issued, single-use grant is bound to the exact plan for up to 60 seconds. Session-wide reuse of action approvals is disabled.

Automation of CAPTCHA/OTP/bypass flows is not supported; the user can carry out these steps personally on the page. Granting site access is not authorization to execute another plan. If a tab changes, re-observe before proceeding.

## Network access and local AI

Public `http_request` research disallows local and private network destinations, including redirect hops. This is distinct from the **explicitly configured HTTP provider** connector, which still supports `http://127.0.0.1:... `, `http://localhost:... `, and LAN-hosted OpenAI-compatible services. Do not place access tokens in public research URLs.

This initial network check resolves DNS before fetching and blocks unsafe resolved addresses; it does **not yet pin** the subsequent connection to the verified IP. For a strict SSRF boundary, use an HTTP transport with DNS-resolution and connection pinning. IPv6 in public research is conservatively denied pending full address classification; local provider connectivity is unaffected.

## Google Gemini API free tier

Under Connector, choose **Google Gemini API (free tier supported)**, enter a Google AI Studio API key, click **Refresh Models**, select a compatible model, then **Save HTTP Provider**. Browser Companion uses Google's officially documented OpenAI-compatible endpoint:
`https://generativelanguage.googleapis.com/v1beta/openai`

Availability, costs and limits depend on your Google project and selected model. A model listed by Google is not necessarily free. Free-tier content may be used by Google to improve its products. Check https://ai.google.dev/gemini-api/docs/pricing and https://ai.google.dev/gemini-api/docs/openai.

Google Antigravity is a separate agent/IDE offering. Browser Companion does not authenticate with Antigravity sessions or reuse Antigravity IDE quotas. The existing Gemini CLI connector remains available independently.

## Detailed debug (opt-in)

For an HTTP provider, select **Detailed HTTP debug** before saving. It is OFF by default and can be switched OFF again. When enabled, the native host writes the HTTP request body and error artifacts under `~/.browser-companion/debug/` with owner-only permissions on POSIX systems. Request artifacts can contain complete prompts or page context, so do not enable this when dealing with sensitive material. Disable the option and delete old artifacts from that directory when finished.

The ordinary side-panel diagnostic logs remain sanitized. Existing artifacts generated by earlier versions at the repository root are not deleted automatically.

## Recovery and testing

The native host rejects malformed input frames, limits frame size and uses bounded timeouts for HTTP providers by default. Pending approval tokens intentionally disappear on service-worker restart: the user must approve the plan again.

Run `npm test`, `npm run test:attachments`, and `npm run test:memory` before merging. Automated tests cover policy invariants and local-only diagram rendering. Dynamic end-to-end tests for service-worker suspension, authenticated local models, and DNS rebinding should be added before claiming comprehensive coverage.
